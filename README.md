# 隱含估值追蹤

用兩段式 DCF 把一檔股票的「市場隱含成長率」和「我自己估的成長率」並排比較，
兩者的落差就是判斷貴或便宜的訊號。追蹤清單存成一檔一列的表格，可裝到手機當 App 用。

**網站：** <https://abc15642394-ctrl.github.io/implied-valuation/>

## 這個模型在算什麼

EPS 先用「1-5 年成長率」成長五年、再用「6-10 年成長率」成長五年，逐年折現，
第 10 年之後套永續成長公式算終值再折現回來。兩個方向：

- **合理價**：給定我估的成長率 → 算出股價應該是多少。
- **市場隱含成長率**：給定目前股價 → 用二分搜尋反推市場正在假設的 1-5 年成長率。

**落差 = 市場隱含 − 我估的**。負值代表市場的要求比我低，也就是相對低估。

表格另外顯示**永續價值佔比**，因為終值往往佔合理價一半以上——佔比越高，
估值越是靠「第 10 年後還好好活著」這個假設撐著，數字要打折看。

## 模型的邊界

- EPS ≤ 0 不適用：此時股價對成長率是遞減的，反推會收斂到錯誤方向，所以直接擋下。
- 折現率必須大於永續成長率，否則終值公式會算出無限大或負數。
- 反推範圍是 −90% ~ 300%，超出就明講求不出解，不會回一個假數字。

## 資料存在哪

**這個 repo 裡沒有任何持股資料**，`docs/` 底下也沒有寫死任何同步網址。
但「不會上傳到任何地方」已經不是事實了——現在有三個去處，列清楚比較誠實：

| 去處 | 放什麼 | 什麼時候 |
|---|---|---|
| 瀏覽器的 **localStorage** | 全部資料。Safari、加到主畫面的 app、LINE 內建瀏覽器**各存一份，互不相通**（Apple 的設計），所以 app 右上角會標出你在哪一份 | 一直 |
| 你自己的 **secret gist** | 整份資料的副本，由你按「同步 → 推上 gist」主動推 | 只有你按的時候 |
| GitHub 的 **repo secret** | 推播訂閱資訊（哪支手機要收通知），由你自己貼 | 一次性設定 |

後兩項都是**選用**的，而且 gist id 與 token 只存在你自己的裝置上、不會被推出去。
不設定的話，整個 app 的行為跟以前一樣：純 localStorage，右上角提醒你上次匯出多久以前。

有設定的話：備份提醒會改看「上次**推上 gist**是多久以前」，手機則顯示「電腦 N 天前」
好讓你知道手上這份有多舊。詳見 [`通知設定指南.md`](通知設定指南.md)。

每個交易日傍晚還有一個 GitHub Actions 會抓上市櫃的收盤價寫進 `docs/prices.json`
（那是公開的市場資料，跟你的估值無關），app 可以一鍵帶入現價。

## 開發

純靜態、無建置步驟。網站在 `docs/`，GitHub Pages 直接服務該資料夾。

```
python3 -m http.server 8000 --directory docs
```

`.github/scripts/` 底下是收盤價與通知的腳本，以及兩套測試。**改完請跑過**：

```
node .github/scripts/test_store.mjs
node .github/scripts/test_notify.mjs
```

它們不裝任何東西、不碰網路、不需要 secret，鎖住的是幾個踩過的坑
（「未估」不能當成 0%、秘密不能進同步的 state、公開的 Actions log 不能印出估值、
三處版本號必須同步）。CI 的 workflow 最後一步也會跑這兩套。

`web-push` 是唯一的執行期依賴，只有 Actions 的通知腳本用到：`npm ci`。

`popup.html` / `popup.js` / `manifest.json` 是這個工具最早的 Chrome 擴充套件版本，保留未動。
