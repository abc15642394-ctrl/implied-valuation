# 隱含估值追蹤

用兩段式 DCF 把一檔股票的「市場隱含成長率」和「我自己估的成長率」並排比較，
兩者的落差就是判斷貴或便宜的訊號。追蹤清單存成一檔一列的表格，可裝到手機當 App 用。

**網站：** <https://abc15642394-ctrl.github.io/implied-valuation/>

## 這個模型在算什麼

EPS 先用「1-5 年成長率」成長五年、再用「6-10 年成長率」成長五年，逐年折現，
第 10 年之後套永續成長公式算終值再折現回來。兩個方向：

- **合理價**：給定我估的成長率 → 算出股價應該是多少。
- **市場隱含成長率**：給定目前股價 → 用二分搜尋反推市場正在假設的 1-5 年成長率。

**落差 = 市場隱含 − 我估的**。負值代表市場的要求比我低，也就是相對低估。

表格另外顯示**永續價值佔比**，因為終值往往佔合理價一半以上——佔比越高，
估值越是靠「第 10 年後還好好活著」這個假設撐著，數字要打折看。

## 模型的邊界

- EPS ≤ 0 不適用：此時股價對成長率是遞減的，反推會收斂到錯誤方向，所以直接擋下。
- 折現率必須大於永續成長率，否則終值公式會算出無限大或負數。
- 反推範圍是 −90% ~ 300%，超出就明講求不出解，不會回一個假數字。

## 資料存在哪

全部存在你自己瀏覽器的 localStorage，不會上傳到任何地方，這個 repo 裡也沒有任何持股資料。
換裝置或備份請用右上角的「匯出 / 匯入」。網站會提醒你上次匯出是多久以前。

## 開發

純靜態、無建置步驟。網站在 `docs/`，GitHub Pages 直接服務該資料夾。

```
python3 -m http.server 8000 --directory docs
```

`popup.html` / `popup.js` / `manifest.json` 是這個工具最早的 Chrome 擴充套件版本，保留未動。
